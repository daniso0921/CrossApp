## Лабораторна робота №4 — Доменна модель

### Доменні сутності
- `BookCopy` — сутність фізичного примірника книги.
- `Loan` — сутність документа видачі примірника читачеві.

### Реалізовані інваріанти
1. **Обов'язковість ідентифікаторів та текстових полів (`BookCopy.Create`, `Loan.Open`)**: рядок не може бути порожнім чи містити лише пробіли (`ArgumentException`).
2. **Валідність року видання (`BookCopy.Create`)**: рік має знаходитися в історичних межах книгодрукування (1450–2026) (`ArgumentOutOfRangeException`).
3. **Захист від повторної видачі (`BookCopy.Issue`, `Loan.Open`)**: уже виданий примірник не може бути виданий вдруге (`InvalidOperationException`).
4. **Захист від повернення невиданої книги (`BookCopy.Return`)**: не можна повернути примірник, стан якого не є виданим (`InvalidOperationException`).
5. **Хронологія дат видачі та повернення (`Loan.Close`)**: дата повернення не може передувати даті видачі (`ArgumentOutOfRangeException`).
6. **Одноразовість закриття документа (`Loan.Close`)**: закриту видачу заборонено закривати повторно (`InvalidOperationException`).
