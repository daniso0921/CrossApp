# CrossApp

Наскрізний навчальний проєкт з крос-платформного програмування.

## Предметна область
**Бібліотека**
* **Сутності:**
  * `Book` — видання / книга;
  * `BookCopy` — конкретний примірник;
  * `Reader` — читач;
  * `Loan` — видача примірника читачу.
* **Призначення:** облік видач примірників книг читачам та контроль їх повернення.
